# Scry 🔮

*a quiet little mood and habit tracker*

</div>

---

Scry is a place to check in on how you feel, tick off habits and write, then look back
and see what moves together. It wears *Mirrormere*, the still dark lake where Durin
looked in and saw a crown of stars. Tide's sister palette.

It runs entirely in your browser. No account, no server, no ads, no one
peeking. Your data never leaves your device unless you export it yourself.

- **Check-ins**: as many per day as you like, each with a mood, emotions and a note
- **Habits**: your own list, ticked off per day; archive one to keep its history
- **Patterns**: the last 12 weeks at a glance, mood on days with and without each habit, and your most common emotions

## Run it yourself

```sh
npm install
npm run dev
npm test
npm run build
```

It's a static site (React + Vite), so `dist/` can go on any static host.

Raw exports from other apps go in `finch-export/`, which is gitignored.
